# Shield - Ad Blocker Privacy Policy

Last updated: November 15, 2026

Shield - Ad Blocker is a local DNS-filtering application. It uses Android's
VPN service only to receive DNS requests addressed to its local DNS endpoint.
Normal application and web traffic is not routed through Shield.

## Data handling

- Shield does not collect, sell, or share personal information.
- Shield does not include advertising or analytics SDKs.
- Optional block statistics and recently blocked domain names remain on the
  device in the app's private storage. The user can disable local statistics.
- Allowed DNS requests are sent to DNS servers supplied by the active network.
  Public fallback DNS servers may be used when those servers are unavailable.
- The app periodically downloads public domain blocklists from the sources
  credited in the app. Those hosts receive standard connection information,
  such as the device IP address, as part of any internet request.

## Retention and deletion

Local settings and statistics remain until the user clears app storage or
uninstalls Shield. Shield operates no server that stores user data.

## Children

Shield is not directed at children and does not knowingly collect personal
information from anyone.
